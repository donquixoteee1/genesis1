# GENESIS 发布审查 · 2026-10-21

## 已修正

- 2.0.1 将双手与爆散中心固定为画布中心参考坐标，输入框移到底部不会再把手部构图拉出画面。
- 统一名称为 GENESIS，包名为 `codex-genesis-skin`。
- 固定 1/60 秒模拟，每帧最多补算 4 次。显示最多 30 fps，输入时 20 fps。
- 5 秒黑暗阶段只保留一次唤醒定时器，不运行逐帧绘制。
- 离屏、后台、暂停和系统减少动态效果时停止 RAF。
- 每张主画布最多 2,400,000 像素；两个 RGBA 表面的原始像素预算合计最多 19.2 MB。该数值不是浏览器总内存实测值，浏览器、GPU、字体、图层和 JavaScript 堆还有额外开销。
- 前臂延伸至视口外，并与参考手形平滑重叠，靠近时不会露出原图截面；新增宽屏边缘回归测试。
- 字符网格最多 28,000 格。主要高频数据使用固定容量 TypedArray，爆散期间复用缓冲。
- 销毁时取消 RAF/定时器、移除全局监听、断开观察器、释放像素和字符缓冲。支持重复销毁、bfcache 恢复及开发热更新清理。
- 调试全局对象和 200ms 诊断轮询只在开发模式存在，生产版去除。
- 限制演示聊天与附件 DOM 数量；附件输入清空后不保留 File 对象。
- 固定依赖和 lockfile；Vite 升级至 7.3.7，修复审计发现的开发服务器依赖漏洞。
- 背景字符仅使用基本 ASCII，无外部字体、图片、视频、网络请求或用户内容上报。

## 验证范围

35 项自动测试覆盖原始海洋基础模块和现用手部系统，包括时间线、手形、手指连续性、星点运动、输入框虚化、自动播放、减少动态效果、黑暗休眠、资源销毁、30fps 绘制预算、Retina/4K/8K 缓冲上限。

严格 TypeScript 检查、生产网页和独立 ES 模块构建通过；`npm audit` 在审查时返回 0 vulnerabilities。漏洞数据库会更新，应在后续发布时重新审计。

Chromium 桌面预览中检查运行、中文输入和控制台；1440×900 一次靠近阶段采样的绘制耗时为 4.80ms。这不是长期帧时分位数或所有硬件的性能保证。

## 发布边界

官方动态背景 API 尚未确认，网页模块仍标记 `nativeCodexInstallable: false`。第三方 Dream Skin 1.5.21 本地适配单独交付，须由用户同意其 loopback CDP 和重启要求；不修改 Codex 应用签名。浏览器验收与离线完整性检查不能替代原生热更新显示验收。

手部强度数据源自用户提供的参考图片，素材原作者及公开传播授权尚未确认。源代码不包含该图片原件；强度数据仍属于参考衍生素材，不应据此宣称素材已获开放授权。

发布清单不包含参考视频、截图、其他项目文件、登录凭据、node_modules 或本机绝对路径。
